## PySpark Projects Portfolio

This repo is a collection of seven mini-projects that dive deep into distributed computing and big data processing. The projects are really interesting, like a mini version of the PageRank algorithm and parallelized statistical models. This is where I get my hands dirty with PySpark!

These projects are originally assignments from the Data-Intensive Distributed Analytics course (CS 431) at the University of Waterloo. I decided to polish them up and share them here to showcase my journey in learning how to solve programming questions using PySpark. Feel free to check out how I tackled each big data challenge!

---

### Assignment 0: Python Text Analytics Warm-Up
In this introductory assignment, we analyze the complete text of Shakespeare's plays using pure Python. We calculate the top 50 most frequent words in his works and build a co-occurrence dictionary to find words that repeatedly follow the word "perfect" on the same line.

**Main Concepts**: Python proficiency, file I/O operations, text tokenization, working with dictionaries

---

### Assignment 1: Pointwise Mutual Information (PMI) Analysis
In this assignment, we calculate the Pointwise Mutual Information (PMI) of tokens in Shakespeare's plays to understand the probability of words co-occurring on the same line. We develop a system to answer one-token and two-token queries, returning either the number of co-occurrences and PMI for a pair or the top five highest PMI words for a single token based on a given threshold.

**Main Concepts**: Calculating probabilities, working with large dictionaries/Counters, heap data structures, computational complexity

---

### Assignment 2: Distributed Pointwise Mutual Information (PMI) Analysis
In this assignment, we transition our PMI analysis of Shakespeare's text from pure Python to a distributed computing model using Apache Spark. We rewrite the previous assignment's functions to calculate distinct tokens, token pairs, and probabilities in a data-parallel fashion, utilizing Spark RDD transformations and actions to optimize processing efficiency across clusters.

**Main Concepts**: Apache Spark, Resilient Distributed Datasets (RDDs), parallel processing, Spark transformations (map, flatMap, distinct) and actions (count, take), distributed probability calculations

---

### Assignment 3: Spark Graph Analysis & Personalized PageRank
In this assignment, we use Apache Spark to perform distributed graph analysis on the Gnutella server network. First, we extract basic graph properties (node counts, edge counts, and in/out-degree distributions). Then, we implement a Single Source Personalized PageRank algorithm to identify the most relevant nodes relative to a specific source node.

**Main Concepts**: Distributed graph processing, Personalized PageRank algorithm, handling adjacency lists, calculating distributions (in-degree/out-degree), iterative algorithms in Spark, MapReduce framework

---

### Assignment 4: Spam Detection using Stochastic Gradient Descent
In this assignment, we build and apply spam classification models using training datasets and stochastic gradient descent (SGD). We train multiple models to predict whether test documents are spam or ham, exploring how shuffling the training data instances affects the resulting model weights using Spark's sorting capabilities.

**Main Concepts**: Spam classification, Stochastic Gradient Descent (SGD), machine learning with Spark, training vs. testing datasets, impact of data shuffling on model training, MapPartitions processing

---

### Assignment 5: Relational Data Analysis using Spark SQL and DataFrames
In this assignment, we transition from the original Spark RDD interface to the newer Spark DataFrame API to analyze relational (tabular) data. Working with datasets modelled after the TPC-H benchmark, we load files into DataFrames and perform operations analogous to SQL queries to answer business-oriented analytical questions.

**Main Concepts**: Spark SQL, Spark DataFrames, Relational Data Processing, TPC-H Benchmark Schema, SQL Querying, Data aggregation and manipulation

---

### Assignment 6: Real-time Data Streaming Analysis with Spark
In this concluding assignment, we process live streaming data generated by ultrasound sensors on a wall-navigating robot. Using Spark Streaming, we aggregate the incoming telemetry data over rolling time windows to calculate and report the ratio of distinct movements the robot performs in real-time.

**Main Concepts**: Spark Streaming, DStreams, real-time data processing, rolling time windows (window functions), streaming transformations, foreachRDD output collection
